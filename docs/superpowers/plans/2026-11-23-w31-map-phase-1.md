# W31 Trend Report — Interactive Map, Phase 1 (Landing → Gate → Memory Field) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get the W31 report running locally on the new reusable "Interactive Map" (`map`) template: landing page, "What stuck?" prompt bar, the existing sign-up gate (copied), and a data-driven Memory Field with a theme detail panel.

**Architecture:** One additive branch in the shared template router lazy-loads `src/components/map/ReportView.tsx`, so the map code and CSS only download for `map` reports. The reusable template (`src/components/map/`) renders the page shell; everything W31-specific lives in `src/components/map/reports/w31/`. That covers theme data (`themes.ts`, counts only; every percentage, size and total is calculated in `themeMath.ts`), copy (`content.ts`) and design tokens (`brand.css`). All CSS selectors are scoped under `.map-root`.

**Tech Stack:** Next.js 16 (App Router, static export), React 19, TypeScript, Sanity v5, plain scoped CSS. Tests use Node 24's built-in test runner (`node --test`), which runs `.ts` files directly via type stripping, so no new dependencies are needed.

**Spec:** `docs/superpowers/specs/2026-11-23-w31-trend-report-design.md`

## Review Focus

1. **Theme counts that change or are all zero.** Changing one count must update every number with no `NaN`/`Infinity`. All-zero counts must render `0%`, not crash. *(pinned in Task 2: `zero total` test)*
2. **Pole totals rounding to 101% or 99%.** e.g. a 50.5/49.5 split must show 51%/49%, not 51%/50%. *(pinned in Task 2: `pole labels always sum to 100` test)*
3. **A new theme added without a position.** It must land inside its own half (Meaning left, Form right), not at 0,0. *(pinned in Task 2: `auto position stays in its half` test)*
4. **Data entry mistakes in `themes.ts`** (duplicate id, negative or fractional count, unknown pole). These must be caught by a test, not shipped silently. *(pinned in Task 2: `validateThemes` tests + `seed data is valid` test)*
5. **Map CSS or code leaking into other reports.** Other reports must not download or be styled by map code. *(pinned in Task 1: lazy import; Task 9: build + scope diff + spot-check of one horizontal and one vertical report)*

Outer-ring stops 01–05 and their modals, 06 Meaning / 07 Form panels, Takeaways, the bottom tour nav and Index button, the phone layout, the Vercel branch-only preview project, moving content into Sanity fields, and storing "Drop it in" answers.

```js
  const s = computeThemeStats([t('a', 'meaning', 30), t('b', 'meaning', 10), t('c', 'form', 60)])

  assert.equal(s.themes.find((x) => x.id === 'c').label, '60%')

  assert.equal(s.poles.meaning.label, '40%')
  assert.equal(s.poles.form.label, '60%')

  const before = computeThemeStats([t('a', 'meaning', 50), t('b', 'form', 50)])

  assert.equal(before.poles.meaning.label, '50%')
```

```ts
// Pure functions that turn theme COUNTS into everything shown on the
// Memory Field. Nothing here is typed in by hand: change a count in
// themes.ts and every percentage, size and total follows.
//
// Kept free of imports and non-erasable TypeScript so `node --test`
// can run it directly.

export type Pole = 'meaning' | 'form'

export interface ThemeAnswer {
  project: string
  why: string
}

export interface Theme {
  id: string
  name: string
  pole: Pole
  /** Coded answers that LEAD with this theme. */
  count: number
  color: string
  /** Text color used on top of `color`. */
  ink: string
  /** CSS clip-path for the blob's outline. */
  shape: string
  line: string
  copy?: string
  /** Center of the blob on the 1440×900 canvas. Omit to auto-place. */
  position?: { x: number; y: number }
  answers: ThemeAnswer[]
}

export interface ThemeStat extends Theme {
  share: number
  label: string
  size: number
  x: number
  y: number
}

export interface PoleStat {
  count: number
  share: number
  label: string
}

export interface ThemeSummary {
  total: number
  themes: ThemeStat[]
  poles: Record<Pole, PoleStat>
}

/** The design canvas the field is drawn on (scaled to the screen). */
export const CANVAS = { width: 1440, height: 900, divider: 720, maxBlob: 191, minBlob: 36 }

export function formatShare(share: number): string {
  if (!share) return '0%'
  if (share < 0.005) return '<1%'
  return `${Math.round(share * 100)}%`
}

/** Meaning/Form labels that always add up to 100% (largest remainder). */
export function poleLabels(meaningCount: number, formCount: number): Record<Pole, string> {
  const total = meaningCount + formCount
  if (!total) return { meaning: '0%', form: '0%' }
  const m = (meaningCount / total) * 100
  let mr = Math.floor(m)
  let fr = Math.floor(100 - m)
  if (mr + fr < 100) {
    if (m - mr >= 100 - m - fr) mr += 1
    else fr += 1
  }
  return { meaning: `${mr}%`, form: `${fr}%` }
}

/** Fallback spot for a theme with no hand-set position, inside its own half. */
export function autoPosition(indexInPole: number, pole: Pole): { x: number; y: number } {
  const col = indexInPole % 3
  const row = Math.floor(indexInPole / 3) % 5
  const x0 = pole === 'meaning' ? 360 : 850
  return { x: x0 + col * 120, y: 300 + row * 110 }
}

export function validateThemes(themes: Theme[]): string[] {
  const errors: string[] = []
  const seen = new Set<string>()
  for (const t of themes) {
    if (seen.has(t.id)) errors.push(`duplicate id "${t.id}"`)
    seen.add(t.id)
    if (!Number.isInteger(t.count) || t.count < 0) {
      errors.push(`theme "${t.id}": count must be a whole number of 0 or more (got ${t.count})`)
    }
    if (t.pole !== 'meaning' && t.pole !== 'form') {
      errors.push(`theme "${t.id}": pole must be "meaning" or "form" (got "${t.pole}")`)
    }
  }
  return errors
}

export function computeThemeStats(themes: Theme[]): ThemeSummary {
  const total = themes.reduce((sum, t) => sum + t.count, 0)
  const maxCount = Math.max(0, ...themes.map((t) => t.count))
  const poleIndex: Record<Pole, number> = { meaning: 0, form: 0 }

  const stats: ThemeStat[] = themes.map((t) => {
    const share = total ? t.count / total : 0
    // Area (not width) is proportional to share, so size scales with the square root.
    const size = t.count && maxCount
      ? Math.max(CANVAS.minBlob, Math.round(CANVAS.maxBlob * Math.sqrt(t.count / maxCount)))
      : 0
    const pos = t.position ?? autoPosition(poleIndex[t.pole], t.pole)
    poleIndex[t.pole] += 1
    return { ...t, share, label: formatShare(share), size, x: pos.x, y: pos.y }
  })

  const meaningCount = themes.filter((t) => t.pole === 'meaning').reduce((s, t) => s + t.count, 0)
  const formCount = total - meaningCount
  const labels = poleLabels(meaningCount, formCount)

  return {
    total,
    themes: stats,
    poles: {
      meaning: { count: meaningCount, share: total ? meaningCount / total : 0, label: labels.meaning },
      form: { count: formCount, share: total ? formCount / total : 0, label: labels.form },
    },
  }
}

export function rankPole(summary: ThemeSummary, pole: Pole): ThemeStat[] {
  return summary.themes
    .filter((t) => t.pole === pole)
    .sort((a, b) => b.count - a.count || a.name.localeCompare(b.name))
}
```

```ts
import type { ComponentType } from 'react'

export interface NavLink {
  label: string
  href: string
  primary?: boolean

export interface TickerItem {

  color: string
}

/** All copy for one map report. Moves into Sanity fields in Phase 3. */
export interface MapContent {

  reportTitle: string
  reportSubtitle: string
  landing: {
    eyebrow: string
    headlineTop: string
    headlineCircled: string
    subtitle: string
    nav: NavLink[]
  }
  prompt: {
    question: string
    placeholder: string
    button: string
    ticker: TickerItem[]
  }
  focusLock: {
    eyebrow: string
    headline: string
    button: string
  }
  gate: {
    title: string
    subhead: string
  }
}

export interface CenterProps {
  selectedId: string | null
  onSelect: (id: string | null) => void
}

export interface PanelProps {
  id: string
  onClose: () => void
}

/** Everything report-specific the reusable map template needs. */
export interface MapReportConfig {
  /** Extra class on .map-root that scopes the report's brand.css. */
  className: string
  content: MapContent
  Center: ComponentType<CenterProps>
  Panel: ComponentType<PanelProps>
}
```

```ts
// Grey "feed" dots behind the field. Seeded so they're identical on the
// server and in the browser (no hydration mismatch) and on every visit.
export function makeDots(count: number, seed: number) {
  let s = seed >>> 0
  const rand = () => {
    s = (s + 0x6d2b79f5) >>> 0
    let t = s
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
  return Array.from({ length: count }, () => ({
    x: Math.round(rand() * 1440),
    y: Math.round(rand() * 900),
    r: Math.round(3 + rand() * rand() * 22),
    o: Math.round((0.15 + rand() * 0.45) * 100) / 100,
  }))
}
```

```tsx
'use client'

import { useEffect, useRef, useState } from 'react'
import type { MapReportConfig } from './types'

const W = 1440
const H = 900

export function MapStage({
  config,
  locked,
  onUnlock,
  selectedId,
  onSelect,
}: {
  config: MapReportConfig
  locked: boolean
  onUnlock: () => void
  selectedId: string | null
  onSelect: (id: string | null) => void
}) {
  const stageRef = useRef<HTMLDivElement>(null)
  const [scale, setScale] = useState(1)
  const { content, Center, Panel } = config

  useEffect(() => {
    const el = stageRef.current
    if (!el) return
    const fit = () => setScale(Math.min(el.clientWidth / W, el.clientHeight / H))
    fit()
    const ro = new ResizeObserver(fit)
    ro.observe(el)
    return () => ro.disconnect()
  }, [])

  useEffect(() => {
    if (!selectedId) return
    const onKey = (e: KeyboardEvent) => e.key === 'Escape' && onSelect(null)
    window.addEventListener('keydown', onKey)
    return () => window.removeEventListener('keydown', onKey)
  }, [selectedId, onSelect])

  return (
    <section id="map" className={`map-stage-wrap${locked ? ' is-locked' : ''}`}>
      <header className="map-header">
        <div className="map-brand">
          {content.brandLines.map((l) => <div key={l}>{l}</div>)}
        </div>
        <div className="map-header-title">
          {content.reportTitle} · <span>{content.reportSubtitle}</span>
        </div>
        <div aria-hidden="true" />
      </header>
      <div className="map-stage" ref={stageRef} aria-hidden={locked}>
        <div className="map-canvas" style={{ transform: `translate(-50%, -50%) scale(${scale})` }}>
          <Center selectedId={selectedId} onSelect={onSelect} />
        </div>
        {selectedId && !locked && <Panel id={selectedId} onClose={() => onSelect(null)} />}
      </div>
      {locked && (
        <div className="map-focus-lock">
          <p>{content.focusLock.eyebrow}</p>
          <h2>{content.focusLock.headline}</h2>
          <button type="button" className="map-button" onClick={onUnlock}>
```

This copies the access rules the vertical template uses, so the W31 gate behaves like every other report: a cookie for returning visitors, `?access=direct` to skip, `?reset` to clear, and the CMS on/off switch.

```ts
'use client'

import { useCallback, useEffect, useState } from 'react'
import type { Report } from '@/sanity/types'

function getCookie(name: string): string | undefined {
  return document.cookie
    .split('; ')
    .find((row) => row.startsWith(`${name}=`))
    ?.split('=')[1]
}

function setCookie(name: string, value: string, days: number) {
  const expires = new Date(Date.now() + days * 864e5).toUTCString()
  document.cookie = `${name}=${value}; expires=${expires}; path=/`
}

export function useReportAccess(report: Report) {
  const cookieKey = `report-access-${report.slug.current}`
  const [hasAccess, setHasAccess] = useState(false)

  useEffect(() => {
    const params = new URLSearchParams(window.location.search)
    // Dev shortcut: ?reset clears the signup cookie so the gate shows again.
    if (params.has('reset')) {
      document.cookie = `${cookieKey}=; expires=Thu, 01 Jan 1970 00:00:00 GMT; path=/`
      window.location.replace(window.location.pathname)
      return
    }
    // Shareable "skip the gate" link: this page load only, no cookie.
    if (params.get('access') === 'direct' || report.signupGateEnabled === false || getCookie(cookieKey)) {
      setHasAccess(true)
    }
  }, [cookieKey, report.signupGateEnabled])

  const grantAccess = useCallback(() => {
    setCookie(cookieKey, 'true', 365)
    setHasAccess(true)
  }, [cookieKey])

  return { hasAccess, grantAccess }
}
```

```tsx
import { PromptBar } from './PromptBar'
import { MapStage } from './MapStage'
import { SignupGate } from './SignupGate'
import { useReportAccess } from './useReportAccess'
import './map.css'

/**
 * Interactive Map template. Reusable layout: a central visual with the
 * report's sections as stops around it. Report-specific pieces live in
 * ./reports/<key>/.
 */
export function ReportView({ report }: { report: Report }) {
  const config = getMapReport(report.slug.current)
  const { hasAccess, grantAccess } = useReportAccess(report)
  const [showGate, setShowGate] = useState(false)
  const [selectedId, setSelectedId] = useState<string | null>(null)

  return (
    <main className={`map-root ${config.className}`}>
      <AnalyticsScripts report={report} />
      <Landing content={config.content} />
      <PromptBar prompt={config.content.prompt} />
      <MapStage
        config={config}
        locked={!hasAccess}
        onUnlock={() => setShowGate(true)}
        selectedId={selectedId}
        onSelect={setSelectedId}
      />
      {showGate && (
        <SignupGate
          report={report}
          copy={config.content.gate}
          onClose={() => setShowGate(false)}
          onComplete={() => {
            grantAccess()
            setShowGate(false)
            document.getElementById('map')?.scrollIntoView({ behavior: 'smooth' })
          }}
        />
      )}
    </main>
  )
}
```

Replace `src/components/map/reports/w31/ThemePanel.tsx` with:

```tsx
'use client'

import type { PanelProps } from '../../types'
import { SidePanel } from '../../SidePanel'
import { summary } from './summary'

export function ThemePanel({ id, onClose }: PanelProps) {
  const t = summary.themes.find((x) => x.id === id)
  if (!t) return null
  const poleName = t.pole === 'meaning' ? 'Meaning' : 'Form'

  return (
    <SidePanel onClose={onClose} closeLabel="Back to the field">
      <p className="w31-panel-eyebrow">{poleName}</p>
      <div className="w31-panel-stat">
        <span className="w31-panel-swatch" style={{ background: t.color, clipPath: t.shape }} />
        <span className="w31-panel-pct">{t.label}</span>
      </div>
      <h2 className="w31-panel-headline">{t.name}: {t.line}</h2>
      <p className="w31-panel-copy">
        {t.label} of the {summary.total} coded answers led with this reason.
        {t.copy ? ` ${t.copy}` : ' [Copy TK: what it means for people making work.]'}
      </p>
      {t.answers.length > 0 && (
        <>
          <p className="w31-panel-eyebrow">In their words</p>
          {t.answers.map((a) => (
            <figure key={a.project} className="w31-panel-answer">
              <figcaption>{a.project}</figcaption>
              <blockquote>“{a.why}”</blockquote>
            </figure>
          ))}
        </>
      )}
    </SidePanel>
  )
}
```
